# Fontes estáticas

Instâncias estáticas usadas para gerar a imagem de compartilhamento e os ícones (`lib/og.tsx`), porque o gerador de imagens do Next.js não aceita fontes variáveis. No site, as fontes são carregadas pelo `next/font`.

| Arquivo | Família | Licença |
|---|---|---|
| `Archivo-ExpandedBold.ttf` | Archivo (largura 125%, peso 700) | SIL Open Font License 1.1, ver `OFL-Archivo.txt` |
| `Archivo-SemiExpandedSemiBold.ttf` | Archivo (largura 112,5%, peso 600) | SIL Open Font License 1.1, ver `OFL-Archivo.txt` |
| `Archivo-Regular.ttf` | Archivo (peso 400) | SIL Open Font License 1.1, ver `OFL-Archivo.txt` |
| `JetBrainsMono-Medium.ttf` | JetBrains Mono (peso 500) | SIL Open Font License 1.1, ver `OFL-JetBrainsMono.txt` |
